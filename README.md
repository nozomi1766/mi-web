# Nozomiweb - Portfolio Creativo & Proyecto Personal

¡Bienvenidx a **Nozomiweb**! Este es mi rincón personal en la web donde reúno mis diferentes pasiones artesanales y creativas: desde acuarelas y bordados hasta cosplays y proyectos hechos a mano.

🌐 **Puedes visitar la web oficial aquí:** [nozomi1766.github.io/mi-web/](https://nozomi1766.github.io/mi-web/)

---

## 💡 ¿Cómo nació este proyecto?

Este proyecto nació de la necesidad de tener un espacio propio e independiente donde mostrar todo lo que creo. Quería salir de la rutina y ponerme a prueba: **aprender desarrollo web básico desde cero**.

Mi objetivo principal no solo era tener un portfolio bonito para compartir mis manualidades, sino también **retarme a mí misma** a entender cómo funciona internet por dentro, perdiéndole el miedo al código y maquetando mi propia web paso a paso.

---

## 🛠️ Tecnologías y Herramientas

Para la construcción de este sitio he utilizado:

- **HTML5:** Estructura semántica de todas las páginas de la web.
- **CSS3:** Estilos personalizados, colores pastel, animaciones y diseño adaptativo.
- **Bootstrap 5:** Componentes para la barra de navegación y maquetación flexible.
- **Git & GitHub Desktop:** Control de versiones y despliegue continuo en **GitHub Pages**.
- **Visual Studio Code:** Editor de código.
